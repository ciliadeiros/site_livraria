# site_livraria
Este repositório contém um projeto elaborado como atividade avaliativa durante o 3° ano do curso de Informática para Internet do IFRN CA.
Em sumo, trata-se de um site semelhante ao Skoob, onde o usuário cria sua biblioteca virtual; desenvolvido usando a linguagem Python com Flask, Flask_login e SQLite.

# Como rodar localmente o nosso site
Inicialmente, deve-se baixar os arquivos disponibilizados na pasta "site_livraria". Feito isso, como o site possui um ambiente virtual, é necessário habilitar esse ambiente para colocá-lo na web. Para isso, siga as instruções:

## Ativando o Ambiente Virtual
1. Primeiramente, abra seu prompt de comando e localize a pasta onde foi salvo os arquivos do site (ex.: cd Downloads/site_livraria)
2. Use o comando 'venv\Scripts\activate' para ativar o ambiente virtual
   
   *OBS.: caso o flask e o flask_login não estejam instalados, é preciso rodar os comandos 'pip install flask' e 'pip install flask_login' para baixá-los e, dessa forma, fazer o código funcionar corretamente.*
3. Para desativar o ambiente, primeiro clique no atalho 'CTRL + C' e depois digite 'deactivate'
